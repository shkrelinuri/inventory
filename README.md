# Inventory Manager

A small browser-based inventory manager for organizing materials by category. You can add, edit, search, and remove items, and switch between English and Italian.

## Try it locally

Open `index.html` in a browser. The app has no build step or external dependencies, and saves inventory data in that browser's `localStorage`.

This is a front-end prototype, not a secure inventory service: it has no server or database, and its login screen is not real authentication. Data is local to the browser and is not shared between users or devices.
